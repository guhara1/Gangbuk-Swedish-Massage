# 바로GO — 강북 출장마사지·홈타이 안내 사이트

서울 강북구 전지역 방문 관리(출장마사지·홈타이) 안내용 정적 사이트입니다.
예약전화: **0508-202-4719**

## 구조

- 정적 HTML 사이트 — 어느 호스팅(GitHub Pages, Netlify, 일반 웹서버)에서든 그대로 서빙 가능
- `build.py` + `content/` 패키지에서 페이지를 생성하는 빌드 방식
- 생성물(각 디렉터리의 `index.html`, `sitemap.xml`, `robots.txt`)도 저장소에 포함

```
build.py            # 빌드 스크립트 (레이아웃·글자수 검사·sitemap 생성)
content/
  site.py           # 상호(바로GO)·전화·BASE_URL·메뉴 구조
  main.py           # 메인 페이지 (+ HealthAndBeautyBusiness/FAQPage JSON-LD)
  areas.py          # 대표 행정동별: 강북구 허브 + 대표 동 9개
  stations.py       # 지하철역별: 허브 + 11개 역(4호선·우이신설선)
  districts.py      # 생활권·주요 거점별: 허브 + 8개 거점
  themes.py         # 테마별: 허브 + 14개 테마
  info.py           # 출장마사지 안내·코스·예약·가이드·후기·고객센터·약관
  magazine.py       # 매거진(에디토리얼) 허브 + 아티클 6편
  about.py          # 운영자 소개(E-E-A-T)
assets/             # CSS, 모바일 내비 JS, OG·파비콘 이미지
```

## 빌드

```bash
python3 build.py
```

빌드 시 페이지별 본문 글자수 리포트가 출력됩니다.

## 사이트 구성 (총 페이지)

- 메인 1
- 대표 행정동 9 (삼양동·미아동·송중동·송천동·삼각산동·번동·수유동·우이동·인수동) + 허브 1
- 지하철역 11 (미아사거리·미아·수유 = 4호선 / 솔샘·삼양·삼양사거리·화계·가오리·4.19민주묘지·솔밭공원·북한산우이 = 우이신설선) + 허브 1
- 생활권·주요 거점 8 + 허브 1
- 테마 14 + 허브 1, 매거진 6 + 허브 1, 안내·약관·운영자 소개 등

## SEO 운영 원칙 (빌드에 강제됨)

- 본문 **2,000자 미만 페이지는 자동 `noindex`** 처리되고 sitemap에서 제외
- 행정동은 대표 동 9개만 — 번1·2·3동은 번동, 수유1·2·3동은 수유동으로 통합 (숫자 행정동 단독 페이지 없음)
- 역은 역 1개당 페이지 1개 — 노선별·방향별·출구별 분리 없음, 예정역(동북선 등) 단독 색인 페이지 없음
- **지역+역+테마 조합 페이지 없음** (도어웨이 방지) — 테마는 독립 페이지로만 운영
- 생활권 페이지는 실제 검색 의도가 있는 거점만, 역·행정동 페이지와 내용이 겹치지 않게 작성
- 상단/하위 메뉴와 푸터에 키워드·지역명·역명 대량 나열 없음
- 실제 영업장 주소가 없는 방문형 사이트이므로 LocalBusiness Schema는 사용하지 않음

## 배포 전 해야 할 일

1. `content/site.py`의 `BASE_URL`을 실제 도메인으로 변경
2. `python3 build.py` 재실행 (canonical·sitemap·robots.txt에 반영됨)
3. Google Search Console에 `sitemap.xml` 제출
